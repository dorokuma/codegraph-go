# Shutdown hang fix

## Root cause

Idle shutdown closed the daemon transport, then server cleanup closed `BgDone` and blocked in `BgWg.Wait()`. Extraction checked that signal, but the subsequent full resolution pass did not. Noise cleanup and synthesis also continued after shutdown.

The incident DB contains all **23,634 files** and **1,077,222 pending references**. The 23,500 message was a progress interval, not evidence of extraction stopping there. Repeated per-reference import queries can rescan import edges (`idx_edges_kind`, followed by file filtering), explaining read amplification; no historical CPU profile proves its exact share of the incident's 4.5 TB reads.

The initial local baseline reproduced the hang: after idle shutdown, its SIGQUIT stack showed main waiting in cleanup and background work still in `ResolveAll` / `edgeWriter.flush`. Reviewer A subsequently confirmed additional reachable cancellation gaps in incremental reference scans, noise symbol lookups and synthesis graph reads. Those gaps are included in this repair.

## Files changed

- `internal/extraction/{shutdown.go,orchestrator.go,orchestrator_file.go,noise.go}`: adapt the existing done channel to a context, propagate it through post-extraction work, cancel file-scoped cleanup and symbol reads, use context-aware file lists for deletion/pruning, and stop between atomic file-deletion units. Preserve `ErrIndexInterrupted` and the unmarked-revision contract.
- `internal/server/server.go`: check `BgDone` before starting optional Git-assist probing; retain its existing public signature and in-flight timeout.
- `internal/db/{query_refs.go,query_files.go,query_nodes.go,query_edges.go}`: context-aware full/file/name/empty-tail reference, import, node-kind/node-ID and graph-edge reads; check cancellation between paginated buffered callbacks. Preserve legacy background-context wrappers, SQL selection/deduplication and limits.
- `internal/resolution/{resolver.go,name_matcher.go,import_resolver.go}`: full/incremental context propagation and loop checks; do not age canceled references or flush unprocessed plans. Once cancellation is observed, do not initiate new transactions or fallback writes. Already-started transactions are not context-bound and complete atomically; an in-flight `ApplyResolvedRefs` batch may resolve some refs while the rest remain pending, so a declining pending count does not imply reference loss.
- `internal/resolution/{synthesize.go,synth_fnptr.go,synth_goframe.go}`: context-aware supporting graph reads, `classMethods`, pass loops and merge/conversion checks. Preserve the atomic synthesized-edge replacement boundary.
- Existing tests `internal/db/query_test.go`, `internal/extraction/interrupt_test.go`, `internal/resolution/{resolver_batch_test.go,synth_fail_test.go}`, `internal/sync/watcher_test.go`: active SQLite cancellation, writer/rows release, buffered callback cancellation, resolution with an unflushed plan and retry control, cancellation inside React `classMethods`, pass entry and normal-path controls. Follow-up deletion regressions cancel inside the first real `ClearFile` transaction, preserve remaining files, verify normal deletion, and exercise bounded watcher `WaitIdle` after releasing the in-flight transaction. Superseded new `shutdown_test.go` files were consolidated and removed.
- `CHANGELOG.md` and this report. Preexisting server argument-unwrapping changes remain separate and untouched.
